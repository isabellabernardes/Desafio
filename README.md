# 💰 Sistema Bancário em Java

Projeto desenvolvido como desafio prático do curso **Criando a Primeira Aplicação em Java**, da [Alura](https://www.alura.com.br/).

## 📌 Sobre o projeto

Este projeto consiste em uma aplicação bancária simples executada pelo terminal, que simula algumas operações básicas de uma conta corrente. O programa permite consultar o saldo, realizar transferências e adicionar valores ao saldo da conta.

O objetivo foi praticar os fundamentos da linguagem Java, desenvolvendo a lógica de programação e trabalhando com estruturas de controle e entrada de dados.

## 🚀 Funcionalidades

- **Consultar saldo:** exibe o saldo atual da conta.
- **Transferir valor:** permite transferir um valor, desde que exista saldo suficiente.
- **Receber valor:** adiciona um valor ao saldo da conta.
- **Sair:** encerra a execução do programa.

## 🛠️ Tecnologias utilizadas

- Java
- `Scanner` para leitura de dados digitados pelo usuário.
- Estruturas condicionais (`if` e `else if`).
- Estrutura de repetição (`while`).
- Variáveis e operações aritméticas.
- Text Blocks para exibição do menu.

## ▶️ Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone URL_DO_SEU_REPOSITORIO
   ```

2. Acesse a pasta do projeto.

3. Compile o arquivo Java:

   ```bash
   javac Desafio.java
   ```

4. Execute a aplicação:

   ```bash
   java Desafio
   ```

**Pré-requisito:** ter o JDK (Java Development Kit) instalado e configurado no computador.

## 📚 Aprendizados

Durante o desenvolvimento deste desafio, pratiquei conceitos fundamentais de Java, como:

- Declaração e utilização de variáveis.
- Leitura de informações pelo terminal.
- Estruturas condicionais para controlar as operações.
- Laços de repetição para manter o menu em execução.
- Manipulação de valores numéricos.
- Atualização do saldo a partir de operações matemáticas.
